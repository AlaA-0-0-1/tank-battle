# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas 写的单文件坦克大战游戏,无需任何依赖、无需服务器,双击即可游玩。所有像素画面和音效均为程序化生成(原创素材)。

## 🎮 如何运行

- **本地游玩**:直接用浏览器打开 `index.html` 即可。
- **在线游玩**:在 GitHub 仓库启用 GitHub Pages(`Settings → Pages → Deploy from a branch → main`),即可通过 Pages 链接游玩。

## 🕹 操作

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 继续 |
| `R` | 重新开始 |

## ✨ 玩法与特性

- **目标**:守住中央的红色旗帜基地,消灭来袭的敌军坦克,尽可能推进更多波次。
- **4 种敌人**:
  - 灰色「基础」—— 速度慢,普通威胁
  - 红色「快速」—— 移动飞快
  - 绿色「掉落」—— 击败后掉落道具(会闪烁白光)
  - 黄色「装甲」—— 需 4 次命中才能摧毁
- **地形**:砖墙(可打穿)、钢墙(满火力可打穿)、水面(挡坦克、不挡子弹)、树林(隐藏坦克)。
- **道具**:★ 提升火力 · 盾 临时护盾 · 爆 全歼场上敌人 · 命 加一条命 · 钟 冻结敌人。
- **难度递增**:波次越高,敌人越多、越快、装甲越多,无限挑战。
- **音效**:Web Audio 合成音效,无需外部音频文件。

## 🛠 技术说明

- 纯原生 JavaScript + Canvas,无框架、无构建步骤。
- 最高分保存在浏览器 `localStorage` 中。
- 像素美术通过 `makePixelSprite` 以字符画方式定义,运行时旋转生成四个朝向。
